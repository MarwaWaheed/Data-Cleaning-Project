# Data Cleaning Project Using Python

## Project Overview
This project focuses on cleaning and preparing a sales transactions dataset using Python and Pandas. The goal is to improve data quality and ensure the dataset is ready for further analysis and visualization.

## Data Cleaning Steps
- Inspected the dataset structure and data types.
- Identified and handled missing values.
- Removed duplicate records.
- Converted the `Date` column to datetime format.
- Removed extra spaces from text columns.
- Checked for invalid values in `Age`, `Quantity`, `Rating`, and `Discount`.
- Verified the uniqueness of transaction IDs.
- Exported the cleaned dataset to a CSV file.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Output
The final output is a cleaned CSV file ready for further data analysis and visualization using tools such as Power BI or Python.

## Skills Demonstrated
Data Cleaning, Data Preprocessing, Missing Value Handling, Duplicate Removal, Data Type Conversion, and Data Quality Validation.
